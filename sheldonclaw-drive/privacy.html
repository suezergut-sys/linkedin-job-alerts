Privacy Policy

SheldonClawDRIVE · Last updated 26 October 2026

A private Google Drive synchronization and backup integration for an owner-operated OpenClaw environment.

Purpose and authorization

The application accesses only Google accounts authorized by their owners. It requests https://www.googleapis.com/auth/drive to synchronize an existing Obsidian folder and manage independent backups. This permission technically allows viewing, creating, changing and deleting all Drive files, except application-specific data outside the scope. The configured operations target designated vault and backup folders.

Data accessed and transferred

rclone reads file and folder names, identifiers, sizes, modification times, checksums and file contents needed for synchronization and backup verification. Files in the configured folders may include private notes, attachments and other information chosen by the owner. No actual user files or personal records are published on this website.

File contents and metadata are transferred between Google Drive and the operator's private server. Independent backups may also be retained on the operator's local computer and Google Drive. Synchronization is not a substitute for an independent backup.

Processing and other services

Synchronization and checksum verification are performed by software on the operator's server. The Drive transport itself does not send file contents or OAuth credentials to an AI model. Other separately authorized OpenClaw workflows may read or process the private vault, including through configured model providers, and may communicate with the owner through Telegram. This notice does not grant permission for those separate actions.

The operator does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. Information obtained through Google APIs is used for the authorized functionality and must comply with the Google API Services User Data Policy, including its Limited Use requirements. Any separately authorized processing must use compatible provider terms and settings.

Storage and protection

OAuth credentials are stored in restricted private files outside public source control and outside the working Obsidian vault. Private server storage holds synchronized files, operational state, logs and version backups. Independent backup archives may contain private records and configuration and are not placed in public repositories.

Retention and deletion

There is no automatic retention deadline for the owner's source records or independent backups. Removing a working file can propagate to the other synchronized location; configured version backups may retain displaced copies. Deleting a working file or revoking OAuth access does not automatically remove copies from backups or operational records.

The owner can stop synchronization, remove application-held credentials and arrange deletion of selected records and retained backup copies. Deletion is not claimed until it has been confirmed. Authorized users can request review through their existing private contact with the operator.

Control and revocation

Access can be revoked through Google Account's third-party connections page. Revocation prevents future authorized Drive access; it does not by itself delete already synchronized files, logs or backups. Google may also invalidate authorization under its own policies.

This website

These pages have no application JavaScript, analytics tags, advertising, forms or page-set cookies. GitHub Pages hosts the site and may process technical request information under GitHub's privacy statement. Visiting this site does not connect a Google Drive account.

Contact and changes

Use the support email displayed on Google's consent screen or your existing private contact with the operator. Material changes to access or data use require updated notices and any additional authorization required by the account owner or Google.
